# SawEars User Guide
This guide is aimed at the general user of SawEars. It is a non-technical document
focused of practical use of the application.

# What is SawEars?
SawEars is a pedagogical application aimed at players of the musical saw, or other
continuous pitch instruments such as the theremin. 

# Getting started
The basic flow of the application is as follows:
1. From the main screen, click [REF] to go to the song selection screen
2. Search the available options and select a song to play
3. On the Lesson Settings screen, adjust lesson settings (for more detail see the Lesson Settings section of this guide)


# Settings menu
The settings menu can be reached by clicking the gear icon in the top app bar.

## Instrument
Here you can set the playable range of your instrument. This is the highest and lowest note your instrument can produce.
